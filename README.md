# Secure Multiparty Communication Systems

An overview of end-to-end encrypted group messaging, covering deployed protocols like Sender Keys and MLS, proposed improvements, their practicality, and protection against misbehaving group members. This repository contains a paper and presentation created as part of the _Seminar on Internet Technology_ at RWTH Aachen University.
