\subsection{2-Party E2EE}
The most prominent and currently well-established protocol for pairwise communication is often called the Signal Protocol.
It uses the Double Ratchet system to achieve both FS and BS in chat messages.

(Symmetric and DH)

\subsection{Client-side fanout}
The naive approach to scale this existing protocol for group chats would be client-side fanout.
By creating pairwise channels between all group members, a de facto group chat is created.
For a group of size $n$, each individual is required to create $n-1$ channels and every sent message needs to be encrypted $n-1$ times.
Because of this, malicious group members could send completely different messages to different members of the group without being caught.
